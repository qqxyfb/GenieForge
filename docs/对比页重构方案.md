# 对比页（工具 → 对比差异）重构方案

> 状态：待实施（分析完成 2026-10-08）
> 对应 TODO：#20

## 一、现状与问题

系统目前有两套对比，定位不同：

| 页面 | 入口 | 现状 | 定位 |
|------|------|------|------|
| CompareView | 数据页「对比…」→ `/compare/:table/:id` | 单实体并排只读对比，字段级差异高亮 + 应用 | 已较好，单实体粒度 |
| **DiffView** | 工具 → 对比差异 | 选基准 + 目标 dat，全量 diff 出报告 | **体验差，本次重构对象** |

DiffView 的问题（用户反馈）：

1. 只支持选「基准 dat + 目标 dat」两个文件，不能按已管理版本对比；
2. 需要手选基准文件——实际基准就是当前已加载的 dat，应固定；
3. 变更记录只有名称，没有 id，无法定位；
4. 缺少「跳转到该数据项」和「差异详情（子弹窗 + 应用）」；
5. 展开内容是英文字段名 + 原始数字/英文值，可读性差。

## 二、目标

把 DiffView 从「选两文件全量 diff」重构为：

> **以当前 dat 为基准，选一个版本（或文件）作为目标，全量 diff 出带 id 的变更清单，
> 每条记录可「跳转到数据页修改」或「打开详情子弹窗（数据页并排对比 + 应用）」。**

## 三、核心设计

### 3.1 基准固定为当前 dat

- 后端 `diff` 引擎新增 `diff_current(target_path)`：基准直接用 `dat_core.get()`（内存对象，**不再重复 parse 基准**），目标 parse 一次。
- 收益：省掉一次 dat parse（约 12s），且语义上就是「当前工作内容 vs 目标版本」。

### 3.2 目标改为「选版本」为主、「选文件」为辅

- 目标入口改为版本下拉（复用 `version_store.list()` + `version_store.snapshot_path()`）。
- 保留「选文件」作为补充（对比任意 dat，不落版本库）。

新增后端接口：

```
POST /api/diff/against-version   body: { version_id }
→ 以当前 dat 为基准，版本快照为目标，返回 DiffReport
```

### 3.3 变更记录带 id

`core/diff.py` 的报告记录补 id：

- `modified`：已有 `id_a`（基准 id）/`id_b`（目标 id）；
- `added` / `removed`：补 `id`（新增/删除记录在各自表中的 id）。

### 3.4 差异跳转

每条变更记录加「跳转」按钮 → `router.push` 到对应数据页并定位实体：

- techs → `/techs?id=<id>`
- effects → `/effects?id=<id>`
- civs → `/civs?id=<id>`
- unit_headers → `/units?civ=0&id=<id>`（单位需带 civ）

### 3.5 差异详情子弹窗（类 IDEA）

每条变更记录加「详情」按钮 → 打开 Dialog 子弹窗，内嵌**数据页并排对比画面**：

- 复用 CompareView 的单实体并排对比渲染逻辑，抽成可复用组件 `EntityCompareDialog`；
- 弹窗内：左=当前 dat（可应用）、右=目标版本（只读），差异高亮 + 「应用」按钮；
- 应用后走命令栈可撤销，与数据页「对比…」一致。

实现要点：CompareView 目前从全局 `compare.state` 读目标版本，需改造成**接受 props 指定目标版本 id**，使子弹窗可独立指定版本。

### 3.6 展开内容可读化

- 字段名：复用 `compare/fields.ts` 的 `FIELDS` 定义，把英文字段 key 映射为中文 label；
- 枚举值：复用 `meta` 枚举（armors / resource-types / civ-resources 等），数字显示为「数字 名称」；
- 子表：按 `columns` 渲染列，而非整行 JSON。

## 四、实施步骤

| 步骤 | 内容 | 涉及文件 |
|------|------|---------|
| 1 | 后端：`diff_current`（基准用内存）+ 记录补 id | `core/diff.py` |
| 2 | 后端：`POST /api/diff/against-version` | `api/diff.py` |
| 3 | 前端：DiffView 顶部改「选版本 + 选文件」+ 记录表加 id/跳转/详情列 | `views/DiffView.vue` |
| 4 | 前端：抽 `EntityCompareDialog`（CompareView 逻辑改 props 指定版本） | 抽组件 + `CompareView.vue` |
| 5 | 前端：展开内容可读化（字段中文 + 枚举名称） | `DiffView.vue`（复用 fields/meta） |

## 五、数据流

```
当前 dat（内存 dat_core.get()）
        │
        ├─ 基准（不 parse）
        │
        ▼
  POST /api/diff/against-version {version_id}
        │  parse 版本快照（一次）
        ▼
  DiffReport { table, records[含 id], id_drift, summary }
        │
        ├─ 表格行「跳转」→ 数据页定位修改
        ├─ 表格行「详情」→ EntityCompareDialog（并排 + 应用）
        └─ 展开 → 字段中文 + 枚举名称
```

## 六、验收标准

1. 打开「工具 → 对比差异」，无需选基准，直接选目标版本即可对比；
2. 变更记录每行有 id，点「跳转」能到对应数据页定位到该实体；
3. 点「详情」弹出并排对比弹窗，可逐字段应用并撤销；
4. 展开内容为中文字段名 + 枚举名称，不再出现英文键名 + 裸数字。
