## 用户新反馈（2026-10-07，验收 v0.3.0 界面改版后）

### 10. 文明页「文明资源」值列显示 `[object Object]`
- **现象**：文明详情的文明资源（601 项）表格中，「值」列全部显示 `[object Object]`（见用户截图）。
- **期望**：显示数值本身；值列应为可编辑的数字输入。
- **排查方向**：上游重做 CivsView 时 `resources` 的取值映射（`value` 取到了对象）；或后端 `/api/civs/{id}` 返回结构变化后前端未同步。

### 11. 关联面板去除噪音引用
- **现象**：文明页右侧「引用了（1414）」列出全部 601 项资源关联的单位引用，没有信息量；「单位关联文明」同理。
- **期望**：
  - 文明页去除「引用了」面板（或仅显示有意义的引用，如科技树 / 团队加成）；
  - 单位详情去除「关联文明」条目。

### 12. 所有数据页分页支持调整每页数量
- **现状**：分页只有页码，`page_size` 固定（科技/效果 50、单位 500）。
- **期望**：分页栏加 sizes 下拉（如 20 / 50 / 100 / 200 / 500），选择后回到第 1 页并重新拉取。

### 13. 效果页命令级复制粘贴与更灵活的命令卡片
- **现状**：复制 / 粘贴是整实体粒度，效果命令只能整表增删；命令卡片交互单一（仅类型下拉 + 参数 + 删除）。
- **期望**：
  - 支持复制单条 / 多选若干条效果命令，可粘贴到同实体或其他效果（跨实体更好）；
  - 命令卡片增加交互：上移 / 下移排序、插入到指定位置、折叠展开、拖拽排序可选。

### 14. 详情页字体对比度与区块划分
- **现象**：详情页字段标签 / 值的字体颜色对比度不足，看不出哪块数据是什么（见用户截图）。
- **期望**：提高标签与值的颜色层级（标签更淡、值更亮），或为字段分组增加区块边框 / 分组标题强调，按 AGE 视觉迭代。
